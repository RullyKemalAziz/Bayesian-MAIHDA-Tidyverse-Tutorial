This document is a tidyverse translation of the code tutorial accompanying the MAIHDA methodological paper by Evans et al. 2024. It is intended to be read alongside the published paper. For reference, the original tutorial code is also available for comparison.

2 outcomes are going to be demonstrated here, continuous HbA1c data for linear regression MAIHDA, and binary diabetic status for the logistic MAIHDA.

This data are based on the original NESARC data:

The original NESARC was a longitudinal study begun in 2001 by the U.S. National Institute on Alcohol Abuse and Alcoholism, and it was designed to survey a representative sample of the U.S. non-incarcerated civilian population, including citizens and non-citizens, aged 18 years and older who were currently residing in the U.S. Wave 2 data was collected between 2004 and 2005.

These are the strata that we will be dealing with:

Following the construction of strata used by Evans et al. (2018), we defined 384 possible intersectional strata (=2 sex/gender categories × 3 race/ethnicity categories × 4 education categories × 4 income categories × 4 age categories) with a total of N = 33,000 individuals. For realism, we simulated some strata to be very small (e.g., N < 10) while others are substantially larger.

Constructing the strata ID

As Evans noted:

Selecting which axes of marginalization or inequality to examine in an intersectional analysis (e.g., age, gender, race/ethnicity, income, sexual orientation, disability) should be based on both theoretical and practical considerations.

Theoretical considerations includes:

  • What are the major axes of marginalization and/or inequality experienced by this population, and in particular, what may be relevant to the outcome of interest?

  • From prior research, What has prior research shown to be important?

Practical considerations include:

  • What the data have, What axes of marginalization/inequality were actually measured in this data set?

  • What is the quality of those measures?

  • How were responses coded. Here like education 4 lvls and so on. It’s important here because if you collapse some, it will change the J total levels you have, and variation will change because it has to move somewhere when categories are collapsed, which then might change the VPC altogether.

  • How large is the sample and how is the sample distributed across possible strata definitions? This is probably the levels with small n concern, which make sense if you have a bunch of strata, the levels will explode.

Here is a paragraph that ilustrate better the 3rd bullet points from the paper:

There are many choices to be made when preparing the variables. For instance, income, education, and age may be provided either continuously or with far more categorical levels than presented here. Decisions about what cutoff values to use or which levels to (re)combine should be supported by theory. However, there is a balance between the ideal set up and practical modeling and data limitations. For instance, using eighteen categories for income would create many small strata after intersecting income with race/ethnicity. While MAIHDA can manage small strata better than some other approaches, it does not entirely avoid the small N problem. In this case, including eighteen income levels would be more granular than is desirable (or needed). As discussed by Evans et al. (2018), the categorizations defined above balance issues of substantive interest with practical data limitations to arrive at a reasonable sample size for most strata.

So although you might want to refer to the theory, you should also balance between meaningful result, and practical modelling decisions.

Next this passage is also important, since you don’t want empty / small n cells:

After provisionally selecting the axes and categories to be included, it is important to consider how well the data available is distributed across all of the possible intersectional strata. For example, unless a survey intentionally oversamples from some minoritized populations (e.g., transgender or non-binary individuals), there may be too few respondents in these categories and this situation will render many strata small or empty after combining with other axes, such as race/ethnicity or class. While it is always desirous to include minoritized populations, data limitations may restrict the axes or categories that are able to be analyzed. When using large population databases with millions of respondents, as in Persmark et al.’s analysis of the Swedish registries (Persmark, Wemrell, Zettermark, et al., 2019), small strata may be less frequent but the available measures of minoritized identities may be more limited. These factors should be considered in the selection of data to work with and in the final specification of strata definitions.

VPC

We will take the posterior draws using as_draws_df() and then hand calculate the VPC. Recall that VPC formula is:

\[VPC = \frac{\sigma^2_u}{\sigma^2_u + \sigma^2_e}\]

where \(\sigma^2_e = \pi^2 / 3 = 3.29\) for logistic models.

# make the VPC calculating function
vpc_draws <- function(model, sigma2_e = NULL) {
  d_draws <- as_draws_df(model)
  su2 <- d_draws$sd_stratum__Intercept^2
  se2 <- if (is.null(sigma2_e)) d_draws$sigma^2 else sigma2_e   # 3.29 for logistic
  su2 / (su2 + se2)                                             # the VPC formula here
}

PCV

The Proportional Change in Variance (PCV) is calculated as:

\[\text{PCV} = \frac{\sigma_{u(\text{Model A})}^2 - \sigma_{u(\text{Model B})}^2}{\sigma_{u(\text{Model A})}^2}\]

Here, Model A refers to the null models. The PCV represents the proportion of the total between-stratum variance (from the simple intersectional model) that is explained by adjusting for the additive main effects.

Now let’s calculate PCV, same workflow as what we’ve done with VPC: make custom function, calculate the PCV, and make it into a tibble.

# make the PCV calculating function: proportional drop in stratum variance, null -> full
pcv_draws <- function(null_model, full_model) {
  su2_null <- as_draws_df(null_model)$sd_stratum__Intercept^2
  su2_full <- as_draws_df(full_model)$sd_stratum__Intercept^2
  (su2_null - su2_full) / su2_null                             # the pcv formula here
}

AUC

The ROCR package is not particularly tidyverse-friendly, and while the yardstick package is an alternative, it includes many other functions that is not used in the MAIHDA workflow. To keep dependencies light, we will write a custom function for the AUC using its rank-based form (the Wilcoxon-Mann-Whitney statistic):

\[U_1 = \left(\sum_{i \in \text{case}} r_i\right) - \frac{n_1(n_1+1)}{2}, \qquad \text{AUC} = \frac{U_1}{n_1 \cdot n_0}\]

Here, \(r_i\) is the rank of the \(i\)-th case. We sum the ranks of all cases and subtract the constant \(\frac{n_1(n_1+1)}{2}\). This removes the within-case comparisons, leaving only the case-versus-non-case comparisons needed for the AUC calculation.

# AUC via the rank (Wilcoxon - Mann -Whitney)
auc <- function(score, label) {
  label <- as.numeric(label)
  r <- rank(score)
  n1 <- sum(label == 1)
  n0 <- sum(label == 0)
  (sum(r[label == 1]) - n1 * (n1 + 1) / 2) / (n1 * n0)
}

For the final panel, we visualize the logistic model’s interaction effects directly in probability space. This plot shows the difference between the total predicted probability for a given stratum \(j\) and the probability based solely on its additive main effects:

\[\pi^B_j = \pi_j - \pi^A_j\]

Where:

  • \(\pi_j\): The total predicted probability in stratum \(j\).

  • \(\pi^A_j\): The predicted probability based on additive main effects only.

  • \(\pi^B_j\): The resulting difference, representing the interaction effect (or stratum-specific random effect) converted into probability space.

Instead of extracting the posterior draws manually and calculating the differences by hand like in the original Evans code, we use add_epred_draws() from the tidybayes package. This function directly samples predictions on the outcome scale for our specified new data (nd_p3b) and returns them in a long-format dataframe.

This approach offers two major advantages:

  1. It eliminates the need to manually specify regression coefficients and calculate expectations by hand.
  2. It avoids the extra data wrangling (such as pivot_longer()) typically required when extracting draws using brms::fitted().
# wrangle with add_epred_draws() from tidybayes
nd_p3b <- distinct(stratum_level, stratum, sex, race, education, income, age)

p3b_data <- nd_p3b |> 
  add_epred_draws(model2B, re_formula = NULL) |>      # π_j: full (with ranef)
  rename(pi_full = .epred) |> 
  left_join(nd_p3b |> 
              add_epred_draws(model2B, re_formula = NA) |>   # π_j^A: additive only
              rename(pi_add = .epred),
            by = c("stratum", "sex", "race", "education", "income", "age", ".draw")) |> 
  mutate(interaction = (pi_full - pi_add) * 100) |>   # difference, per draw, as percentage points
  group_by(stratum) |> 
  median_qi(interaction) |> 
  mutate(rank = rank(interaction))
